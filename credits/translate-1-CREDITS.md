# Translation models hosted for LuceVoce (release translate-1)

The language files of LuceVoce's on-device translation, copied unchanged from Mozilla's Firefox translation models,
https://github.com/mozilla/firefox-translations-models (an archived repository, Mozilla Public License 2.0).

- Directions: English with Romanian, French, German, Spanish and Italian, both ways. For each: the model
  (model.<pair>.intgemm.alphas.bin.gz), the short list (lex.50.50.<pair>.s2t.bin.gz) and the vocabulary
  (vocab.<pair>.spm.gz).
- Licence: Mozilla Public License 2.0, https://mozilla.org/MPL/2.0/ (the text: LICENSE-MPL-2.0.txt in this release).
  The files are the source form, unchanged, so they are available here and at Mozilla as the MPL asks.

No changes made. Sizes and SHA-256 of every file are in LuceVoce's source, which checks each download against them.
